# The Knight in the Panther's Skin (ვეფხისტყაოსანი) — Interactive Animated Web Edition

A zero-dependency, 100% static interactive website for Shota Rustaveli's *The Knight in the Panther's Skin* (*ვეფხისტყაოსანი*), designed for instant deployment on [GitHub Pages](https://pages.github.com/) with no backend or paid domain required.

## Features
- **65-Chapter Animated Plot Stage**: Custom SVG visual scenes, key philosophical aphorisms, and active character badges for every chapter.
- **Synchronized Quest Map**: Interactive map of Arabia, the Royal Hunting Plain, the Devis' Cave, the Seven Kingdoms of India, Khataeti, Mulghazanzar, Gulansharo, and the Fortress of Kadjeti with animated travel trajectories.
- **Complete Unabridged Bilingual Corpus**:
  - **1,669 Georgian stanzas (6,676 lines)** from the 1966 Akaki Shanidze & Aleksandre Baramidze critical edition ([Anbani.db / Georgian Wikisource](https://github.com/Anbani/anbani.db/blob/master/datasets/vefxistyaosani.csv)).
  - **1,576 English stanzas** from Marjory Scott Wardrop's classic 1912 translation ([Allgeo Digital Archive](https://www.allgeo.org/index.php/en/266-shota-rustaveli-the-knight-in-the-panther-s-skin)).
  - **Official Scholarly Commentary**: Grounded in works by Academician Elguja Khintibidze ([Georgian Encyclopedia](https://www.georgianencyclopedia.ge/en/form_eng/903)), Prof. Zaza Khintibidze ([Tbilisi State University](https://e-learning.tsu.ge/mod/resource/view.php?id=111669)), Academician Aleksandre Baramidze ([TSU](https://e-learning.tsu.ge/mod/resource/view.php?id=98600)), and the [National Parliamentary Library of Georgia](http://www.nplg.gov.ge/civil/vefkhistkaosani.html).
- **Works Offline & on GitHub Pages**: Double-click `index.html` locally on your computer or push the folder straight to a GitHub repository.

## How to Publish on GitHub Pages (Free, No Custom Domain Needed)
1. Create a new public repository on GitHub (for example, `vepkhistkaosani-interactive`).
2. Upload all files in this folder (`index.html`, `.nojekyll`, `css/`, `js/`, and `data/`) to the `main` branch.
3. In your repository on GitHub, go to **Settings → Pages**, select **Deploy from a branch**, choose **`main`** and **`/ (root)`**, and click **Save**.
4. Within 1–2 minutes, your site will be live at `https://<your-github-username>.github.io/vepkhistkaosani-interactive/`.
